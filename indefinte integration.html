Indefinite Integration: Fundamental Forms f(x) vs. f(mx) vs. f(mx + n)

📊 Slide 1: Power Rule Functions
Slide 1
🎯 Objective: Compare indefinite integration for algebraic power functions xn (n ≠ −1) and x−1 under linear differential transformations dx = d(mx)m and dx = d(mx + n)m.

🟢 Integration of Standard f(x)

1. Power Rule (n ≠ −1):

∫ xn dx = xn+1n + 1 + C

2. Reciprocal Function (n = −1):

∫ x−1 dx = ∫ 1x dx = ln|x| + C

🔵 Integration of Scaled f(mx) & General Linear f(mx + n)

1. Scaled Power Rule (n ≠ −1):

∫ (mx)n dx = (mx)n+1m(n + 1) + C
📌 General Linear Form f(mx + n) Example:
∫ (mx + n)k dx = 1m ∫ (mx + n)k d(mx + n) = (mx + n)k+1m(k + 1) + C

2. Scaled Reciprocal Function (n = −1):

∫ (mx)−1 dx = 1m ln|mx| + C
📌 General Linear Form f(mx + n) Example:
∫ 1mx + n dx = 1m ∫ 1mx + n d(mx + n) = 1m ln|mx + n| + C
💡 Golden Rule: Express dx = d(mx + n)m to rewrite ∫ f(mx + n) dx as 1m ∫ f(mx + n) d(mx + n) = 1m F(mx + n) + C.
📊 Slide 2: Exponential, Sine, and Cosine Functions
Slide 2
🎯 Objective: Evaluate antiderivatives of exponential, sine, and cosine functions for standard f(x), scaled f(mx), and linear composed f(mx + n) forms.

🟢 Integration of Standard f(x)

3. Exponential Function:

∫ ex dx = ex + C

4. Sine Function:

∫ sin x dx = −cos x + C

5. Cosine Function:

∫ cos x dx = sin x + C

🔵 Integration of Scaled f(mx) & General Linear f(mx + n)

3. Scaled Exponential Function:

∫ emx dx = 1m emx + C

4. Scaled Sine Function:

∫ sin(mx) dx = −1m cos(mx) + C

5. Scaled Cosine Function:

∫ cos(mx) dx = 1m sin(mx) + C
📌 General Linear Form f(mx + n) Examples:
∫ emx + n dx = 1m emx + n + C
∫ sin(mx + n) dx = −1m cos(mx + n) + C
💡 Golden Rule: Express dx = d(mx + n)m to rewrite ∫ f(mx + n) dx as 1m ∫ f(mx + n) d(mx + n) = 1m F(mx + n) + C.
📊 Slide 3: Tangent and Secant Functions
Slide 3
🎯 Objective: Compare indefinite integrals of logarithmic-trigonometric forms tan x and sec x across standard, f(mx), and f(mx + n) forms.

🟢 Integration of Standard f(x)

6. Tangent Function:

∫ tan x dx = ln|sec x| + C

7. Secant Function:

∫ sec x dx = ln|sec x + tan x| + C

🔵 Integration of Scaled f(mx) & General Linear f(mx + n)

6. Scaled Tangent Function:

∫ tan(mx) dx = 1m ln|sec(mx)| + C
📌 General Linear Form f(mx + n) Example:
∫ tan(mx + n) dx = 1m ln|sec(mx + n)| + C

7. Scaled Secant Function:

∫ sec(mx) dx = 1m ln|sec(mx) + tan(mx)| + C
📌 General Linear Form f(mx + n) Example:
∫ sec(mx + n) dx = 1m ln|sec(mx + n) + tan(mx + n)| + C
💡 Golden Rule: Express dx = d(mx + n)m to rewrite ∫ f(mx + n) dx as 1m ∫ f(mx + n) d(mx + n) = 1m F(mx + n) + C.
📊 Slide 4: Cosecant and Cotangent Functions
Slide 4
🎯 Objective: Compare indefinite integrals of reciprocal trigonometric forms csc x and cot x across standard, f(mx), and f(mx + n) forms.

🟢 Integration of Standard f(x)

8. Cosecant Function:

∫ csc x dx = −ln|csc x + cot x| + C

9. Cotangent Function:

∫ cot x dx = ln|sin x| + C

🔵 Integration of Scaled f(mx) & General Linear f(mx + n)

8. Scaled Cosecant Function:

∫ csc(mx) dx = −1m ln|csc(mx) + cot(mx)| + C
📌 General Linear Form f(mx + n) Example:
∫ csc(mx + n) dx = −1m ln|csc(mx + n) + cot(mx + n)| + C

9. Scaled Cotangent Function:

∫ cot(mx) dx = 1m ln|sin(mx)| + C
📌 General Linear Form f(mx + n) Example:
∫ cot(mx + n) dx = 1m ln|sin(mx + n)| + C
💡 Golden Rule: Express dx = d(mx + n)m to rewrite ∫ f(mx + n) dx as 1m ∫ f(mx + n) d(mx + n) = 1m F(mx + n) + C.
📊 Slide 5: Squared Sine and Cosine Functions
Slide 5
🎯 Objective: Evaluate integrals of sin2x and cos2x using double-angle identities across standard, f(mx), and f(mx + n) forms.

🟢 Integration of Standard f(x)

10. Squared Sine Function:

∫ sin2x dx = ∫ 1 − cos(2x)2 dx = x2 − sin(2x)4 + C

11. Squared Cosine Function:

∫ cos2x dx = ∫ 1 + cos(2x)2 dx = x2 + sin(2x)4 + C

🔵 Integration of Scaled f(mx) & General Linear f(mx + n)

10. Scaled Squared Sine Function:

∫ sin2(mx) dx = x2 − sin(2mx)4m + C
📌 General Linear Form f(mx + n) Example:
∫ sin2(mx + n) dx = x2 − sin(2mx + 2n)4m + C

11. Scaled Squared Cosine Function:

∫ cos2(mx) dx = x2 + sin(2mx)4m + C
📌 General Linear Form f(mx + n) Example:
∫ cos2(mx + n) dx = x2 + sin(2mx + 2n)4m + C
💡 Golden Rule: Use double-angle reduction formulas sin2θ = 1 − cos(2θ)2 and cos2θ = 1 + cos(2θ)2 before applying the differential substitution dx = d(mx + n)m.
📊 Slide 6: Squared Tangent and Secant Functions
Slide 6
🎯 Objective: Evaluate integrals of tan2x and sec2x using Pythagorean identity transformations across standard, f(mx), and f(mx + n) forms.

🟢 Integration of Standard f(x)

12. Squared Tangent Function:

∫ tan2x dx = ∫ (sec2x − 1) dx = tan x − x + C

13. Squared Secant Function:

∫ sec2x dx = tan x + C

🔵 Integration of Scaled f(mx) & General Linear f(mx + n)

12. Scaled Squared Tangent Function:

∫ tan2(mx) dx = 1m tan(mx) − x + C
📌 General Linear Form f(mx + n) Example:
∫ tan2(mx + n) dx = 1m tan(mx + n) − x + C

13. Scaled Squared Secant Function:

∫ sec2(mx) dx = 1m tan(mx) + C
📌 General Linear Form f(mx + n) Example:
∫ sec2(mx + n) dx = 1m tan(mx + n) + C
💡 Golden Rule: Rewrite tan2θ = sec2θ − 1 to integrate directly via ∫ sec2(mx + n) dx = 1m tan(mx + n) + C.
📊 Slide 7: Squared Cosecant and Cotangent Functions
Slide 7
🎯 Objective: Evaluate integrals of csc2x and cot2x using reciprocal Pythagorean identities across standard, f(mx), and f(mx + n) forms.

🟢 Integration of Standard f(x)

14. Squared Cosecant Function:

∫ csc2x dx = −cot x + C

15. Squared Cotangent Function:

∫ cot2x dx = ∫ (csc2x − 1) dx = −cot x − x + C

🔵 Integration of Scaled f(mx) & General Linear f(mx + n)

14. Scaled Squared Cosecant Function:

∫ csc2(mx) dx = −1m cot(mx) + C
📌 General Linear Form f(mx + n) Example:
∫ csc2(mx + n) dx = −1m cot(mx + n) + C

15. Scaled Squared Cotangent Function:

📌 General Linear Form f(mx + n) Example:
∫ cot2(mx + n) dx = −1m cot(mx + n) − x + C

📊 Slide 8: Integration by Parts — x2ex and x2 ln x
Slide 8
🎯 Objective: Apply integration by parts ∫ u dv = uv − ∫ v du across standard, f(mx), and f(mx + n) configurations.

🟢 Repeated Parts: x2ex

16. Standard Form ∫ x2ex dx:

  • Pass 1: Let u = x2, dv = ex dx ⇒ du = 2x dx, v = ex
    ∫ x2ex dx = x2ex − 2 ∫ xex dx
  • Pass 2: Let u = x, dv = ex dx ⇒ du = dx, v = ex
    = x2ex − 2(xex − ex) + C = ex(x2 − 2x + 2) + C

Scaled Form ∫ x2emx dx:

∫ x2emx dx = emxm ( x2 − 2xm + 2m2 ) + C
📌 General Linear Form f(mx + n) Example:
∫ x2emx + n dx = emx + nm ( x2 − 2xm + 2m2 ) + C

🔵 Logarithmic Parts: x2 ln x

17. Standard Form ∫ x2 ln x dx:

  • Let u = ln x, dv = x2 dx ⇒ du = 1x dx, v = x33
    ∫ x2 ln x dx = x33 ln x − ∫ x33 · 1x dx
  • Simplify and integrate remaining term:
    = x33 ln x − 13 ∫ x2 dx = x33 ln x − x39 + C

Scaled Form ∫ x2 ln(mx) dx:

∫ x2 ln(mx) dx = x33 ln(mx) − x39 + C
📌 General Linear Form f(mx + n) Example:
∫ x2 ln(mx + n) dx = x33 ln(mx + n) − 13 ∫ mx3mx + n dx
💡 Golden Rule: For polynomial-exponential products P(x)emx, differentiate the polynomial until zero; for logarithmic products P(x) ln(mx), set u = ln(mx) to eliminate the logarithm via differentiation.
📊 Slide 9: Integration by Parts — Cyclic ex sin x
Slide 9
🎯 Objective: Solve cyclical integrals where integration by parts yields a multiple of the original integral I.

🟢 Standard Cyclic Integral

18. Standard Form I = ∫ ex sin x dx:

  • Pass 1: Let u = sin x, dv = ex dx ⇒ du = cos x dx, v = ex
    I = ex sin x − ∫ ex cos x dx
  • Pass 2: Let u = cos x, dv = ex dx ⇒ du = −sin x dx, v = ex
    I = ex sin x − (ex cos x + ∫ ex sin x dx)
    I = ex sin x − ex cos x − I
  • Solve algebraically for I:
    2I = ex(sin x − cos x) ⇒ I = ex2(sin x − cos x) + C

🔵 Scaled & Linear Cyclic Integrals

Scaled Form ∫ emx sin(mx) dx:

∫ emx sin(mx) dx = emx2m [ sin(mx) − cos(mx) ] + C
📌 General Linear Form f(mx + n) Example:
∫ emx + n sin(mx + n) dx = emx + n2m [ sin(mx + n) − cos(mx + n) ] + C
📌 General Two-Frequency Form ∫ eax sin(bx) dx:
∫ eax sin(bx) dx = eaxa2 + b2 [ a sin(bx) − b cos(bx) ] + C
💡 Golden Rule: When integration by parts yields a repeating integral −I, collect all terms containing I on one side and divide by the coefficient factor to solve for the final antiderivative.
